# 맞춤형 교내외활동 탐색 프로젝트 기획서

## 프로젝트 목적

교내외활동 탐색에 익숙하지 않은 목포대학교 학부생이 관심 분야, 지원 자격, 참여 가능 일정에 맞는 활동을 한곳에서 찾고 신청 마감일을 정확히 확인하도록 돕는다.

현재 학교·학과 공지와 외부 대외활동 사이트에 정보가 흩어져 있다. 학생은 여러 사이트에서 후보를 찾고, 공고를 열어 지원 자격을 확인하고, 활동 일정과 개인 시간표를 비교한다. 1차 프로토타입은 공고 목록과 검색 조건을 한 화면에 배치해 이 과정을 줄인다.

**대표 과업**은 내 조건에 맞는 활동 1건을 선택하고, 지원 자격과 신청 마감일을 확인하는 것이다.

## 주요 기능

| 기능 | 1차 프로토타입 동작 |
|---|---|
| 교내외 공고 통합 목록 | 첫 화면에 교내 비교과 프로그램과 교외 대외활동의 고정 공고 12건을 표시한다. |
| 조건별 검색 | 같은 화면에서 관심 분야, 지원 자격, 참여 가능 일정을 설정한다. 한 가지 조건이나 여러 조건을 적용해 맞는 공고를 표시한다. |
| 공고 선택 및 정보 확인 | 검색 결과에서 공고를 선택하고 지원 자격, 활동 일정, 신청 마감일을 확인할 수 있게 한다. 원문 링크를 제공하고, 불명확한 정보는 ‘확인 필요’로 표시한다. |
| 결과 없음 안내 | 조건에 맞는 공고가 없으면 결과가 없음을 표시하고, 조건을 해제하거나 초기화해 다시 탐색할 수 있게 한다. |

공고 데이터에는 활동명, 교내·교외 구분, 관심 분야, 지원 자격, 활동 일정, 신청 마감일, 원문 링크를 포함한다. **활동 일정은 참여 가능 여부를 판단하는 정보이며, 신청 마감일은 지원 기한을 확인하는 정보다.** 화면에서 두 항목을 구분해 표시한다.

| 3 | 활동 일정이 수업이나 개인 일정과 겹치는지, 언제까지 신청해야 하는지 알고 싶다. | 참여 가능 일정으로 검색하고 활동 일정과 신청 마감일을 각각 표시한다. |

## 1차 구현 범위와 완료 기준

1차 산출물은 고정 공고 12건을 사용하는 클릭형 디지털 프로토타입이다. 후속 검토 범위에는 후보 저장, 선택적 마감 알림, 별도 비교 화면, 실제 신청, 실시간 공고 수집·갱신, AI 추천, 학교 계정 연동이 포함된다.

- [ ] 첫 화면에 교내·교외 공고 12건이 표시되고 조건을 설정할 수 있다.
- [ ] 관심 분야, 지원 자격, 참여 가능 일정이 단독으로 또는 조합해서 적용되며 결과가 선택 조건에 맞게 바뀐다.
- [ ] 공고를 선택하면 지원 자격, 활동 일정, 신청 마감일을 각각 확인할 수 있다. 원문 링크가 표시되고, 불명확한 정보에는 ‘확인 필요’가 표시된다.
- [ ] 결과가 없는 경우 안내를 확인하고 조건을 해제하거나 초기화할 수 있다. 모든 조건을 초기화하면 전체 목록이 다시 표시된다.
- [ ] 사용자가 조건 설정부터 적합한 활동 1건 선택과 지원 자격·마감일 확인까지 완료할 수 있다.
